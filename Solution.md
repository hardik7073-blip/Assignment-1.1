1. Basic roles

A. Browser: the software (Chrome, Firefox) that sends requests and displays web pages.
B. Client: the user’s device and browser, the side that requests information.
C. Server: a computer that stores website files, processes requests, and sends responses.
D. Database: an organized store of data (users, products, posts) that the server reads and writes.

2. HTTP and HTTPS

HTTP = HyperText Transfer Protocol, the set of rules for transferring web data between client and server. Data travels unencrypted.
HTTPS = HyperText Transfer Protocol Secure, which is HTTP plus SSL/TLS encryption, so data cannot be easily read or tampered with in transit.

3. Request-response cycle

A. The user enters a URL.
B. DNS resolves the domain to an IP address.
C. The browser sends an HTTP/HTTPS request to the server.
D. The server processes it (and queries the database if needed).
E. The server sends back a response (status code + content).
F. The browser renders the page.

4. Static website VS Dynamic website

Static Website
a. Displays fixed content that usually remains the same for every user.
b. Mainly uses HTML and CSS to display information.
c. Example: A simple personal portfolio website.

Dynamic Website
a. Displays content that can change based on user input or data.
b. Uses technologies like JavaScript, server-side programming, and databases.
c. Example: An online shopping website.
